🚀WHAT YOU NEED TO KNOW ABOUT A WEBSITE👨🏻‍💻

01

How Websites Work

  • You type a URL

    • www.techup.academy goes into the address bar.

  • Browser sends a request

    • Your browser asks a server for that page.

  • Server responds

    • It sends back HTML, CSS, JS and images. The files become the page you see.

02

VS Code & Folder Structure

  1. Download VS Code
    2.

    Free at code.visualstudio.com - Windows, Mac or Linux.

  2. Install Live Server
    3.

    An extension that refreshes your page every timeyousave

  3. One Folder per Project
    4.

    File → Open Folder. Keep every project self-contained

  4. Name Files Properly
    5.

    Lowercase, no spaces: index.html, ❌not My Page.HTML❌

03

Semantic HTML

  • Screen readers navigate by landmarks

    • Semantic tags tell assistive tech what each section is.

  • Search engines understand you

    • Google ranks well-structured pages more easily
